掲載文の原本:

- TsubuTalk: private repo `next-gen-voice-memo` の `docs/release/` 配下
  (`privacy_policy_v1.0.md` / `ios/privacy_policy_ios_v1.0.md`)。§A(ja) / §B(en) のみを公開し、§C の内部メモは掲載しない。
- Tap Champion: repo `tap-game`（連打名人 / Tap Champion）。iOS / Android 共通の 1 ポリシー + 利用規約。
  §A(ja) / §B(en) が原本。§C〜§I（zh-Hans / zh-Hant / ko / es / fr / de / pt）は本 repo で作成した参考訳で、
  相違時は日本語版が優先する旨を各訳の冒頭に記載。ページ先頭の言語リンク（`#ja` `#en` `#zh-hans` `#zh-hant`
  `#ko` `#es` `#fr` `#de` `#pt`）から各言語へ飛べる。原本を改定したら参考訳も合わせて更新する。

改定時は原本を更新してから本 repo に反映する。
